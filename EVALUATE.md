# Things to evaluate (and how)

1. **Guidance accuracy** - Compare the company's forecast to the real result, FY2021-25. Is it too high or too low, and by how much?
2. **Each alt-data source** - Does it predict past results? Keep it only if it beats "no signal". Log the score.
3. **Overlap between sources** - If two sources move together, they count as one. Keep the better one.
4. **Which drivers matter most** - Change each input by 10%. See which moves profit most.
5. **Yen effect** - Separate "yen moved" from "business changed".
6. **Tri Pointe effect** - Profit with and without its costs.
7. **Bear / base / bull cases** - Does each tell a different, believable story?
8. **Your forecast vs Gyoseki Consensus** - Where do you differ, and why? Write the reason in your own words.
9. **Model checks** - Balance sheet balances. Segments add to total.
